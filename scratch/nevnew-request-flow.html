Architecture · NevNew

How a message becomes a reply

Two entry points proxy through one LiteLLM instance with a three-model free-tier fallback chain. A separate tool bridge is fully wired but never actually fires at chat time — issue #1. A third path lets Claude call a free worker model directly, bypassing LiteLLM entirely.

Data flow · NevNew

How a bug becomes a merged fix

A second, separate automation: real errors in any container's logs get filed, handed to a free AI worker to fix, then reviewed and merged by Claude before redeploying — no human in the loop unless the review gate blocks it.
